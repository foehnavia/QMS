# docs/worklog — наряды Cowork → Claude Code

> [!note] Асинхронный канал задач от «головы» (Cowork) к «рукам» (Claude Code).
> Один наряд — одна единица работы. Живого канала нет: всё состояние — в файлах репо
> под git. Канон — INFRA-013 (волт `_system/INFRASTRUCTURE.md` §7); выжимка — корневой
> `CLAUDE.md` §3.

## Файл наряда

`docs/worklog/NNNN-<slug>.md` — `NNNN` сквозной (`0001`, `0002`…), `<slug>` — краткий,
латиницей. Привязка к задаче потока — в поле «цель» (напр. `QMS-010`).

## Цикл

1. **Cowork** пишет наряд по шаблону ниже; коммитит (или отдаёт пользователю на коммит).
2. **Claude Code** исполняет в `src/`/`tools/`, прогоняет проверки против критериев приёмки,
   коммитит и **дописывает раздел «Отчёт исполнителя»** в этот же файл.
3. **Cowork** ревьюит через мост (git diff + отчёт), обновляет PM в волте, при необходимости
   заводит следующий наряд.

## Шаблон

```markdown
# Наряд NNNN — <заголовок>

- **Задача / цель:** <ID потока + что должно получиться на выходе>
- **Вход:** <какие файлы читать: docs/model/…, docs/specs/…, приложенный срез данных>
- **Что сделать:** <шаги / объём работ>
- **Критерии приёмки:** <проверяемые условия готовности: тесты зелёные, поведение, DDL валиден…>
- **Чего не трогать:** <файлы/слои вне наряда; напр. docs/model — канон, не править>

---
## Отчёт исполнителя (заполняет Claude Code)

- **Сделано:**
- **Коммиты:** <хэши + сообщения>
- **Проверки:** <что прогонял, результат против критериев приёмки>
- **Отклонения / вопросы Cowork:**
```
