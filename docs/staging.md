## Явно отложено (этап 2+)

- Типы измерения с привязкой к размеру + квалитет точности (влияют на расчёты).
- Вычисление `value` из пинов (пока ручная модерация).
- Дедуп ежедневной автовыгрузки (пока ручная загрузка по одному Deviation).
- Контекст обнаружения (במהלך המדגם / מיון 100% / planned) — не работаем вообще.
- הערה יצרן (примечание изготовителя) — не обрабатываем.
