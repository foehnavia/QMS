0. Шрифт, цифры, единицы
Приложение рисует иврит, латиницу и цифры одной строкой, офлайн, на Windows, из onefile-сборки. Докачиваемых шрифтов нет и быть не может: стек собран из того, что присутствует в Windows без установки.
font.ui — весь интерфейс
"Segoe UI", "Arial", "Tahoma"
Стек один, и в нём только семейства, физически присутствующие в Windows. Убрано: system-ui и sans-serif — понятия CSS, в Qt их нет; Selawik в Windows не установлен; Segoe UI Historic — шрифт исторических письменностей, а не ивритский фолбэк. Ивритское покрытие несёт сам Segoe UI, Arial и Tahoma — резерв на старых сборках. Qt получает стек списком семейств: первое найденное выигрывает, отсутствующее молча пропускается.
С-1 открыт до проверки на машине. Стек считается закрытым только после вывода QFontDatabase.families() и writingSystems(family) на целевой Windows — проверку исполняет Claude Code, результат вписывается в эту рамку и в блок токенов. Рассуждением стек не подтверждается.
font.numeric — колонки величин
Семейство то же, отличается один признак: табличные цифры — в колонке величин разряды стоят в столбик. В Qt это признак шрифта, не отдельный файл и не QSS: QFont::setFeature("tnum", 1) из кода (§9). Если выбранное семейство tnum не несёт, семейство не подменяется — включается запасной механизм: величина рисуется делегатом по фиксированному знакоместу QFontMetrics.horizontalAdvance("0"), выравнивание вправо сохраняется. Без табличных цифр разряды не встают в столбик и правое выравнивание бессмысленно — потому у этого пункта есть запасной механизм, а не пожелание.
+0.08 −0.12 +1.40 −0.06
Единицы. Все числа этого документа — логические пиксели при масштабе Windows 100 %. При 125 / 150 % масштабирует Qt (высокое DPI включено на уровне приложения): метрики умножаются целиком, ни одна из них не привязана к пиксельной сетке конкретного снимка. Рамка 1 px остаётся рамкой в один логический пиксель — Qt сам решает, во сколько физических она превратится. Ограничение на этом ярусе одно: высоты строк (40 / 66 / 82 у отклонения, 28 / 43 / 58 у находки) задаются в коде виджета через логическую метрику, а не подбираются под скриншот, иначе при 150 % таблица разъедется.

11. Блок токенов — машиночитаемо
Переносится копированием, не считыванием с картинки. Формат строки: имя · значение · роль, разделитель — табуляция. Один hex может нести больше одного имени: имён 62, различных hex — 44, потому что состояния делят нейтральные значения (например #EAEDF1 — и фон отключённой кнопки, и фон пилюли Sorting). Расхождение «40 ролей против 44 цветов» закрыто так: безымянных цветов больше нет, лишних имён — тоже.
