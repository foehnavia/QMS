# MIS-QMS

Реляционная база **отклонений** производства (импланты/абатменты и инструмент).
Единый источник **архитектуры** (`docs/`) и **кода** (`src/`) — модель оформления
**Repo-central** (ратифицирована 2026-08-05).

## Слои и где что живёт

| Слой | Где | Правило |
|---|---|---|
| Архитектура (канон модели, спеки, справочники) | этот репо, `docs/` | единый источник; в волт не дублируется |
| Код приложения | этот репо, `src/` | — |
| PM-слой (решения, задачи, обсуждения) | волт `50_MIS-QMS/` | указатель на репо — `code-registry` |
| **Данные** (реальные отклонения) | **локально, вне репо и git** | автономны; в git не кладётся целый реальный документ/протокол — отдельные значения не sensitive (см. `.gitignore`) |

## Инвариант данных

Отдельные значения (номер детали `מק"ט`, номер WO `מנה`/`פק"ע`, отдельное заключение на
иврите) сами по себе **не sensitive** — вне собранного документа ценности не несут и
сохраняются штатно (рабочая БД, тесты, примеры). В git и волт не кладётся только **целый
реальный документ/протокол с привязкой к компании** (собранный `אישור חריגה`, протокол
целиком). Работающая база самостоятельна: не коннектится ни с Claude, ни с волтом, ни с git;
парсинг детерминированный (регулярки), без LLM в рантайме.
