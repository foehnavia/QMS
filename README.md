# MIS-QMS

Реляционная база **отклонений** производства (импланты/абатменты и инструмент).
Единый источник **архитектуры** (`docs/`) и **кода** (`src/`) — модель оформления
**Repo-central** (ратифицирована 2026-08-05).

## Слои и где что живёт

| Слой | Где | Правило |
|---|---|---|
| Архитектура (канон модели, спеки, справочники) | этот репо, `docs/` | единый источник; в волт не дублируется |
| Код приложения | этот репо, `src/` | — |
| PM-слой (решения, задачи, обсуждения) | волт `50_MIS-QMS/` | указатель на репо — `code-registry` |
| **Данные** (реальные отклонения) | **локально, вне репо и git** | автономны; в git НИКОГДА (см. `.gitignore`, RULES §5) |

## Инвариант данных

Реальные данные отклонений (WO, номера деталей, ивритские заключения) в git и волт
**не попадают**. Работающая база самостоятельна: не коннектится ни с Claude, ни с волтом,
ни с git; парсинг детерминированный (регулярки), без LLM в рантайме.

## Доступ

- **Claude Code (VS Code)** — нативно, весь репо.
- **Дизайн-голова (Cowork)** — через подключённую папку («Add folder»).

## Статус

Этап — **проработка модели сущностей** (сессии 01–03, консолидация в
`docs/model/_CONCEPT.md`). Проектирование/построение не начато, стек не выбран.
Карта репозитория — `docs/_INDEX.md`.
